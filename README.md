# 面料成分检查

无外部依赖的 Chrome Manifest V3 插件 MVP。主动读取 Amazon、Shein、Zara 商品页的面料成分，在页面右下角显示中文成分、合成纤维占比、0–100 分与提示。界面沿用参考项目的米色纸张、朱红按钮、衬线标题风格。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目目录 `/workspace/fabric-score-check`，无需构建或安装依赖。
5. 打开或刷新支持的商品详情页，展开材质/成分详情，点击页面右下角「检查」，或点击插件图标 →「检查当前商品」。

只打开页面、popup 或设置页不会计次。每次主动检查一个商品计 1 次，包括重复检查和未找到成分的检查；本 MVP 不做商品去重。读取结果在页面面板中显示，可点击「收起」，再从 popup 触发检查。

## 免费次数与离线解锁

免费每日 3 次，按电脑本地日期重置。配额和许可保存在 `chrome.storage.local`；所有标签页通过同一个后台串行计数。清除浏览器扩展数据或卸载会清除记录；修改系统日期也影响计数。

超限提示：**免费次数已用完，解锁请小红书私信「珊哥爱读书」**。

点击 popup 的「输入许可 / 解锁」，在设置页粘贴 `FSC1.` 开头的许可，验证并保存。有效许可解除次数限制；「清除许可」恢复免费模式，保留当日已用次数。

本地生成演示许可：

```sh
node scripts/gen-license.mjs
```

许可是 `FSC1.` + 种子 `fabric-score-check:unlock:v1` 的 SHA-256 小写十六进制摘要，与参考项目同类实现。所有安装共享同一个公开校验值，**不具备防破解或真实支付验证能力**；没有支付服务、联网激活或账号系统。

## 解析与评分

支持 `60% Cotton, 40% Polyester`、`Cotton 60% / Polyester 40%`、`棉６０％，聚酯纤维４０％` 等常见格式，支持中英文同义词、大小写、前后置比例和小数。

- 合成纤维 / 微塑料相关：polyester、nylon / polyamide、acrylic、elastane / spandex / lycra、polypropylene、polyethylene、polyurethane 等。再生涤纶仍归合成纤维。
- 天然：棉、亚麻、大麻、羊毛、蚕丝、羊绒等。
- 再生纤维素：viscose / rayon、modal、lyocell / tencel 单独归类，不算合成塑料纤维。

成分百分比完整且合计约 100%（容许 0.5 个百分点的舍入误差），才给出确定的合成占比和 `round(100 − 合成占比)` 分数。合成占比 ≤20% 为「合成占比较低」，≤50% 为「合成占比中等」，其余为「合成占比较高」。无百分比、未知百分比或合计异常时显示「信息不足」和原因，不归一化补全数据。

**评分为启发式，非检测报告**，不衡量人体安全、实际微塑料排放、耐用性、舒适性或生命周期环境影响。天然与再生纤维素也有环境影响。

## 站点与权限

Amazon 支持 www.amazon.com、co.uk、de、fr、it、es、ca、com.au、co.jp、in、com.br、com.mx 的 `/dp/ASIN` 和 `/gp/product/ASIN` 商品路由；Shein 支持 shein.com 子域的 `-p-数字.html` 路由；Zara 支持 www.zara.com 的 `-p数字.html` 路由。

权限仅 `storage` 与 `activeTab`；host_permissions 仅上述三类商家的域名。为识别地区路径和站内 SPA 跳转，注入匹配这些域的页面，运行时只在识别到商品路由时显示检查面板。不读取其他网站、不发起网络请求、不上传商品文本或许可。

## 已知限制

- **DOM 易变、选择器未真站验收**。本次仅完成离线测试，没有联网或真实 Chrome 商品页验收。
- Amazon 使用多个候选选择器和商品详情容器文本兜底；Shein / Zara 为占位选择器 + TODO，可能无法获取实际成分。
- 内容必须已出现在 DOM 中；不会自动展开折叠区、滚动、绕过登录、验证码或地区限制，也不能识别图片上的标签。
- 成分表含外层、里料、填充等多个独立百分比组时可能合计超过 100%，会提示异常而不评分。复杂混排、多语言、未知纤维及营销描述可能造成漏读或误匹配，请核对原文。
- SPA 路由变化只更新面板状态，不自动检查或计次；安装或更新扩展后需刷新已有标签页。
- 离线许可与本地计次适用于 MVP，不适用于可靠商业授权。

## 开发与测试

```sh
npm test
```

无需 `npm install`，使用 Node.js 20+ 内置测试运行器。模块采用 UMD 式导出：Chrome 使用 `globalThis.FabricScore`，Node 使用 `require`。测试覆盖成分、评分、每日配额、后台并发计数与许可保存、站点路由/提取、manifest 文件存在性。目录映射见 [docs/FEATURE_MAP.md](docs/FEATURE_MAP.md)。
